# Services folder

Yaha har service ki ek .jsx file banao (template: ../NEW_SERVICE_TEMPLATE.jsx).
File ka naam URL banta hai, jaise `web-development-in-bhopal.jsx` -> /services/web-development-in-bhopal/
Page, navbar dropdown, services listing, footer aur sitemap me apne aap aa jayega.
Dropdown me sab services ek hi list me dikhti hain (order meta se, na do to file ke naam ke A-Z hisaab se).
